# 대표 페르소나 4종 — 3차 보정 (Contextual Rewriting)

> 방법론: `methodology-persona-spectrum.md` §4 **③단계(Contextual Rewriting)**
> 입력: `02-convergent-filtering.md`에서 선별된 4종(핵심 지훈 / 확장 수진 / 극단 옥자 / 비활성 하늘)
> 목적: 4종을 **세이프팟(합법·안전 공동구독 플랫폼) 맥락**에 맞춰 실전 적용 가능한 페르소나 카드로 재기술
> 카드 구성: 한 줄 정의 · 프로필 · 핵심 과업(JTBD) · Pain/Goal · 세이프팟 시나리오(Before→After+감정) · 대체 솔루션→전환 이유 · 세이프팟 기능 매핑 · 핵심 메시지 · 성공 지표

## ① 핵심(Core) — 지훈 · 다 켜두고 다 못 보는 멀티호머

- **한 줄 정의**: 여러 OTT를 켜두고 다 못 보지만, 해지·재구독이 귀찮아 못 끊는 헤비 멀티호머.
- **프로필**: IT 스타트업 마케터 / 32세 / 기술 수준 **상**(얼리어답터).
- **핵심 과업(JTBD)**: "안 보는 구독은 안전하게 빼두고, 볼 때만 켜서 **총지출을 최적화**하고 싶다."
- **Pain**: OTT 3개+·월 4만 원+ 지출, 세 번째 슬롯 실사용률 ~15%(좀비). 실지출 2.5배 과소인지 + 매달 반복되는 결정 피로.
- **Goal**: 볼 건 놓치지 않으면서 안 보는 구독 정리. "필요할 때만 켜고, 안 볼 땐 안전하게 빼두기."
- **세이프팟 시나리오**:
  - *Before*: 월말 명세서에서 좀비구독 발견 → *짜증·죄책감* → 해지·재구독 반복이 귀찮아 그냥 방치.
  - *After*: 대시보드가 저사용 슬롯을 '좀비'로 표시 → "이 슬롯, 합법 파티로 돌리면 월 ○○원" 제안 → **원클릭으로 단독구독→파티 전환**, 안 볼 달엔 On/Off. → *안도·통제감*.
- **대체 솔루션 → 전환 이유**: 토스·뱅크샐러드 구독 위젯은 지출을 *보여주기만* 한다. 세이프팟은 **끊고-되메꾸는 행동까지** 이어준다.
- **세이프팟 기능 매핑**: 통합 대시보드 · 좀비구독 알림 · 단독→합법 파티 원클릭 전환 · 월 단위 On/Off.
- **핵심 메시지**: **"안 보는 구독, 안전하게 빼두세요."**
- **성공 지표**: 3번째 슬롯의 파티 전환율 / 월 지출 절감액 인지 정확도 상승 / 대시보드 재방문율.
- **전략 위상**: **상단 깔때기** — 비용 자각 트래픽으로 유입은 크나, 전환은 절감 제안의 강도에 달림.

## ② 확장(Adjacent) — 수진 · 아이 구독을 믿을 이웃과 나누고 싶은 워킹맘

- **한 줄 정의**: 키즈·교육 구독을 이웃과 나누고 싶지만, 아이 계정이 얽히는 게 껄끄러운 워킹맘.
- **프로필**: 워킹맘(마케팅 팀장) / 38세 / 기술 수준 **중**(육아·교육 앱 능숙, 정산 도구는 낯섦).
- **핵심 과업(JTBD)**: "**아이 것도 안심하고 나눌 수 있으면** 교육비를 줄이고 싶다."
- **Pain**: 디즈니+·유튜브 프리미엄·키즈 교육 구독을 가정별 정가 결제. 나누고 싶지만 아이 프로필·시청 기록이 얽혀 사적 공유가 껄끄럽다.
- **Goal**: 믿을 만한 이웃·지인과 안전하게 분담. 아이 프로필·시청 기록은 분리 보장.
- **세이프팟 시나리오**:
  - *Before*: 교육 구독 갱신에 *부담* → 엄마 모임서 "같이 쓸래요?" → *관심 + 조심스러움*(돈·아이계정 얽힘) → 흐지부지.
  - *After*: **실명 인증된 이웃/지인 범위**에서 매칭 → **아이 프로필·시청기록 격리** 보장 → 자동 정산으로 돈 얘기 없이 분담. → *안심·가벼움*.
- **대체 솔루션 → 전환 이유**: 맘카페·단톡방의 비공식 공유가 안고 있던 **먹튀·프로필 노출 불안**을 제거한다.
- **세이프팟 기능 매핑**: 실명 본인인증 · 지인/이웃 범위 매칭 · 프로필 격리 · 자동 정산·에스크로.
- **핵심 메시지**: **"아이 것도, 안심하고 나눠요."**
- **성공 지표**: 키즈·교육 카테고리 파티 생성 수 / 지인 초대 전환율 / 격리 옵션 사용률.
- **전략 위상**: **2차 확장** — 신뢰 민감·재구매율이 높아, 안전 밸류가 가장 잘 팔리는 인접 시장.

## ③ 극단(Extreme) — 옥자 · 인증·정산에서 반복 실패하는 접근성 취약 사용자

- **한 줄 정의**: 앱 인증·정산 단계에서 반복적으로 막히는 디지털·접근성 취약 사용자.
- **프로필**: 은퇴 후 소일거리 / 63세 / 기술 수준 **하**(통화·카톡·유튜브 시청 수준, 저시력 겸함).
- **핵심 과업(JTBD)**: "**누가 대신 세팅해주면** 실수해도 손해 없이 그냥 보고 싶다."
- **Pain**: 본인인증·비밀번호·에스크로 절차에서 반복 실패, 단계 많으면 중도 포기. 미납 알림 처리법을 몰라 파티에서 자주 튕긴다.
- **Goal**: 복잡한 절차 없이, 실수해도 돈이 새지 않는 안전장치 아래에서 그냥 시청.
- **세이프팟 시나리오**:
  - *Before*: OTP·에스크로 입력 화면에서 → *당황·좌절* → 미납 알림에 → *불안·무력감*.
  - *After*: **보호자 위임(대리 관리)** + 큰 글씨·최소 단계·음성/스크린리더 대응 → 실수해도 **에스크로 자동 환불**. → *안심*.
- **대체 솔루션 → 전환 이유**: 지금은 자녀·가족에 전적으로 의존(못 하면 포기). 세이프팟은 **대리 관리 + 안전망**으로 실패해도 손해가 없게 만든다.
- **세이프팟 기능 매핑**: 보호자 위임(대리 관리) · 접근성 UI(큰 글씨·최소 단계·스크린리더) · 미납/오류 시 자동 환불.
- **핵심 메시지**: **"실수해도 돈이 새지 않아요."**
- **성공 지표**: 접근성 모드 온보딩 완주율 / 대리 관리 파티 유지율 / 중도 이탈률 감소.
- **전략 위상**: **매출 타깃이 아니라 포용적 설계의 기준선.** '대리 관리'는 핵심 ③ 민아(총무) 확장과 기능을 공유한다.

> ⚠️ **레민 병기(인증·결제 인프라 과제)**: 외국인 유학생 등 신분·금융 제약층은 국내 본인인증·해외카드에서 가입 자체가 막혀 회색지대로 내몰린다. 옥자와 함께 **'인증·결제 인프라' 로드맵 과제**로 관리 — 외국인등록증 인증·해외 결제수단·다국어 UI. 대학가·외국인 밀집 지역의 숨은 SAM.

## ④ 비활성(Non-user) — 하늘 · 단독구독에 만족하는 저관여층

- **한 줄 정의**: 단일 구독으로 충분해 공동구독의 필요를 못 느끼는, 가장 흔한 미전환 다수.
- **프로필**: 사회초년생 사무직 / 26세 / 기술 수준 **중**(앱은 쓰지만 구독 최적화엔 무관심).
- **거부 이유(Barrier)**: **"번거로움 > 절감액."** 월 1만~1.7만 원은 "그 정도는 낼 만하다"고 여기고, 정산·매칭의 수고가 절감액보다 크다고 판단해 움직이지 않는다.
- **세이프팟이 넘어야 할 장벽**: 마찰이 **0에 수렴**해야 전환 — 가입 3분·정산 자동·기존 구독 그대로 승계.
- **전환 트리거**: 구독 개수 증가(멀티호머화) 또는 **생애 이벤트(자취·결혼·육아)**로 고정비가 부담이 되는 순간.
- **세이프팟 활용 방향**: 지금은 직접 마케팅 우선순위 밖. 대신 이 페르소나를 **로드맵의 '마찰 KPI' 기준점**(온보딩 소요 시간·이탈 단계)으로 삼는다.
- **핵심 메시지(전환 시)**: **"기존 구독 그대로, 3분이면 반값."**
- **전략 위상**: **관찰 대상** — 진입 장벽의 하한(관여도·마찰)을 알려준다.

> 대비: **정호(프라이버시 강경 거부층)**는 신뢰 메시지로도 넘어오지 않는 **진입 장벽의 상한**. "계정 정보 미공유·완전 격리" 구조의 설득력을 시험하는 별도 관찰 대상으로 둔다.
