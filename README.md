# business-research

산업 및 비즈니스 리서치 학습 자료.

## 개요

경영전략 분석 프레임워크를 학습하고, 실제 시장에 적용해 비교 분석하는 저장소입니다.
- **포터의 5가지 힘(Five Forces)** — 산업의 구조적 매력도(수익성)를 외부 경쟁 관점에서 평가
- **가치사슬(Value Chain)** — 기업 내부 활동을 주요활동·지원활동으로 나눠 가치가 만들어지는 지점을 평가
- **핵심 성공 요인(KSF)** — 위 두 분석을 근거로, 신규 진입자가 집중해야 할 성공 요인을 도출(분석→전략의 다리)
- **시장 규모(TAM-SAM-SOM) & 세그먼트 맵** — 위 분석 위에서 "시장이 얼마나 크고, 어디를 노려야 하는가"를 정량으로 답하고 좌표평면으로 시각화
- **문제 정의 → 기회 탐색 (7단계 워크플로우)** — 위 프레임을 실제 사업 아이디어 탐색에 적용. 문제의식에서 출발해 딥 리서치·가설·정량 검증을 거치며 방향을 좁혀 나가는 과정을 기록

동일한 두 시장(음식 배달앱 · OTT 스트리밍)을 단계별 프레임으로 교차 분석해, 외부 구조와 내부 활동이 서로를 어떻게 설명하고 전략으로 이어지는지 확인합니다. 나아가 OTT 시장에서 도출한 문제의식을 실제 사업 기회 탐색으로 발전시킵니다.

## 사례 분석 요약

- **5가지 힘** — 두 시장 모두 강한 구매자 힘과 치열한 경쟁으로 구조적 매력도가 낮음. 다만 배달앱은 라이더 물류망·양면 네트워크 효과라는 물리적 해자가 있는 반면, OTT는 콘텐츠 원가(공급자 힘)와 글로벌 경쟁 탓에 더 가혹한 구조로 평가됨.
- **가치사슬** — 가치가 쌓이는 위치가 정반대. 배달앱은 **하류(운영·물류)**에 해자를 쌓고, OTT는 **상류(콘텐츠 조달)**에서 이익을 공급자에게 빼앗김. 두 프레임이 "배달앱 매력도 > OTT 매력도"라는 같은 결론을 가리킴.
- **KSF** — 배달앱 진입자는 `본업 자산 지렛대 → 라이더 공급 → 지역 밀도 → 멤버십 락인 → 배차 기술` 순으로 집중(쿠팡이츠·DoorDash 등). OTT 진입자는 넷플릭스와 물량 승부를 피하고 `차별화 콘텐츠 → 니치·로컬 → 본업 번들 → 규모 → 과금 다각화` 순으로 집중(디즈니+·쿠팡플레이·크런치롤 등).
- **시장 규모(TAM-SAM-SOM)** — 글로벌 오리지널 OTT를 **시청시간·MAU** 기준으로 산정하니, 넷플릭스는 한국에서 이용자 점유(~40%)보다 **시청시간 점유(57.7%)가 훨씬 높은 over-indexing**을 보임. 즉 글로벌 강자의 해자는 규모가 아니라 **몰입**이며, 세그먼트 맵(이용자규모×시청몰입도)에서 넷플릭스만 우상단(규모형 몰입 지배자)을 독식함 — 신규 진입자는 좌상단(니치 고몰입)에서 출발해 우상단으로 북동진하는 경로만 현실적(KSF `니치→규모`와 일치).
- **문제 정의 · 기회 탐색** — OTT 이용자의 '비용 누수·탐색 피로'를 출발점으로 사업 기회를 탐색하며 두 번 방향을 틀었고(B2C 애그리게이터 → B2B 취향 데이터 → 공동구독 시장), 그 과정과 기각 이유를 모두 기록.
- **공동구독 시장** — 한국 OTT 공동구독 중개는 구독 관리 3갈래(공동구독·통합관리앱·통신사 번들) 중 유일한 독립 흑자 모델(피클플러스 영업이익률 ~20%). 다만 공유 의향층(SAM ~1,500만) 중 중개 플랫폼 이용은 ~100만(6~7%)뿐 — 신규 진입자는 피클과 정면 승부(좁은 SOM)보다 **넷플릭스 단속·약관 회색지대를 회피하는 합법 모델로 미조직 1,400만을 조직화**하는 데 승산이 있음.
