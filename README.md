# business-research

산업 및 비즈니스 리서치 학습 자료.

## 개요

경영전략 분석 프레임워크를 학습하고, 실제 시장에 적용해 비교 분석하는 저장소입니다.
- **포터의 5가지 힘(Five Forces)** — 산업의 구조적 매력도(수익성)를 외부 경쟁 관점에서 평가
- **가치사슬(Value Chain)** — 기업 내부 활동을 주요활동·지원활동으로 나눠 가치가 만들어지는 지점을 평가

동일한 두 시장(음식 배달앱 · OTT 스트리밍)을 두 프레임으로 교차 분석해, 외부 구조와 내부 활동이 서로를 어떻게 설명하는지 확인합니다.

## 사례 분석 요약

- **5가지 힘** — 두 시장 모두 강한 구매자 힘과 치열한 경쟁으로 구조적 매력도가 낮음. 다만 배달앱은 라이더 물류망·양면 네트워크 효과라는 물리적 해자가 있는 반면, OTT는 콘텐츠 원가(공급자 힘)와 글로벌 경쟁 탓에 더 가혹한 구조로 평가됨.
- **가치사슬** — 가치가 쌓이는 위치가 정반대. 배달앱은 **하류(운영·물류)**에 해자를 쌓고, OTT는 **상류(콘텐츠 조달)**에서 이익을 공급자에게 빼앗김. 두 프레임이 "배달앱 매력도 > OTT 매력도"라는 같은 결론을 가리킴.
